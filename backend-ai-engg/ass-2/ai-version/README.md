## Identified Differences & Code Review

1. **Bug in DELETE Endpoint (Silent 204 on Unknown ID):**  
   The AI code runs `DELETE FROM tasks WHERE id = ?` and commits without inspecting `cursor.rowcount`. If an ID does not exist, it quietly returns `204 No Content` instead of the required `404 Not Found`.

2. **Deprecated FastAPI Lifespan:**  
   The AI used `@app.on_event("startup")` which is officially deprecated in modern FastAPI in favor of `@asynccontextmanager` lifespans.

3. **Missing Indexing & Foreign Key Pragmas:**  
   The AI version omitted table indexes (`idx_tasks_done`) and did not enable `PRAGMA foreign_keys = ON;`.

4. **Missing Transaction Management in Seeding:**  
   The AI executed individual `execute()` statements without a wrapping transaction context manager (`with conn:`), risking inconsistent state if an insertion failed midway.
